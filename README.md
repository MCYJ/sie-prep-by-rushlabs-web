# SIE Prep by RushLabs website

Static marketing and study-guide website for the independent RushLabs Securities Industry Essentials exam-preparation app.

```sh
npm run build
npm run check
```

Production: <https://mcyj.github.io/sie-prep-by-rushlabs-web/>

Add a guide in `content/articles.mjs`, link it from the relevant topic cluster, then rebuild. Publish another locale only when it has a real SIE audience and fully localized substantive content.
